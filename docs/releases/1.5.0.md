**BLINK 1.5.0 can leave the cable behind.** The board can now be fed over your home WiFi, a settings page on your computer holds everything you set up, and BLINK can keep your figures fresh when Claude Code is not running, if you say yes.

## What changed

- **WiFi, if you want it.** The board can talk to your computer over your home WiFi instead of the USB cable. The cable stays the default and still wins: plug it in and the board uses it within seconds. Set it up from the settings page (below), on the **Connect** tab: **Move to WiFi**, pick your network, type its password. The cable is needed once, to hand the board the network and pair it with this computer. After that the link is encrypted, the board is found again when its address changes, and firmware updates go over WiFi with the same safety as over the cable. 2.4 GHz WPA2 networks only; the README's "WiFi" section has the full list of limits. **Forget WiFi** on the page or under **Settings > Connection** on the board deletes the network and the key.
- **One settings page on your computer.** Tap **Settings > Open on PC** on the board, or run **`blink settings`**. The page holds the theme, your logo (PNG, JPG, SVG or animated GIF), WiFi and the board's settings, with a drawing of your board that follows every change.
- **A new Settings screen on the board.** Six tiles, three by two: Brightness, Open on PC, Focus, Update, Connection and About. **Connection** says how the board is reaching your computer (USB, WiFi or None). **About** shows the board's name, its firmware version, the app version on your computer and how long it has been on.
- **Spend on usage-billed seats.** On a Claude seat billed by usage, the panel shows the month's spend against the seat's cap: exact right after `/usage`, estimated from Claude Code's own cost figures in between.
- **Claude Code inside WSL.** `blink install --wsl <name>` reads Claude Code running in one named WSL distribution while BLINK and the board stay on Windows. A plain install never looks into WSL.
- **Keeping figures fresh, opt-in.** BLINK runs `claude -p /usage` with your own Claude Code and login, only when no other source has given a figure in the last 15 minutes, someone is at the computer (input in the last 30 minutes; on Linux, which cannot report that, another Claude source has been in use in that time) and the board is answering, and at most every 25 minutes. It sends no message to the model: measured at zero turns and zero cost, and BLINK turns the refresh off by itself if an answer ever shows otherwise. It also turns itself off after a day of nothing but failures (at least 6 of them). BLINK still never holds a token or calls Anthropic itself.
- **How you are asked.** `blink install` and `blink update` ask once (default Yes on a personal login, No on a work login). If you already have BLINK, the board asks "Keep figures fresh?", with **Turn on** and **No thanks**. Closed without an answer, it asks again the next day, at most 3 times in all; **No thanks** is final.
- **The 5-hour figure should refresh too, but nobody has seen it yet.** We tested on accounts with a weekly limit only, on macOS and Windows. Claude Code keeps the 5-hour figure beside the weekly one, and BLINK reads both the same way, so a plan with a 5-hour limit should get its session figure refreshed as well. If yours stays stale while the weekly one moves, tell us.
- **Turn it on or off any time** with `blink config usage-refresh on` or `off`. `blink status` shows where it stands. It is not available for WSL yet.
- Anthropic's terms restrict automated use of consumer accounts, so this stays off until you decide. The README has the details under "Keeping figures fresh".

## Known limits

- **Plugging the cable into a board on WiFi can restart it once.** On our desk the board restarted about 4 seconds after the cable went in, four times in five. It comes back by itself and nothing is lost.
- **A board with flash encryption cannot get WiFi by itself.** Its firmware has no radio, so it needs the factory tool once. Write to us if that is yours.
- **Keeping figures fresh needs Claude Code 2.1.120 or newer.** On an older Claude Code it is not offered, and `blink status` says to update it; once you do, it starts on its own.

- If you switch Claude logins while your computer's clock is running fast, and the clock is then put right, the new login's figures stay hidden for as long as the clock was ahead. BLINK does not trust readings dated in the future, because a fast clock can otherwise show the old login's figures as the new one's.

## Updating

Run **`blink update`** to install this version, then the screen offers the firmware and one tap installs it. Your settings, theme and logo are kept, and the board stays on the cable until you move it to WiFi.

The question about keeping figures fresh comes from the new version, so the update itself does not ask it. Afterwards, run `blink update` again (it says "Already up to date" and then asks), or `blink config usage-refresh on`, or answer on the board when it asks. The refresh stays off until you answer.

Something wrong? Email **support@blink-buddy.com** with the output of `blink status` and the last lines of `bridge.log`.
