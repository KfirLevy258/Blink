**BLINK 1.0.2 makes updating work on every Mac.** If you installed 1.0.0 or 1.0.1 on a Mac, please install this one by hand -- see below.

## What changed

- **Updates on macOS.** The Mac app could only reach the update feed on a Mac that happened to have a particular Python installed. On any other Mac, `blink update` said the feed could not be read, and the screen never offered an update. The app now carries its own list of trusted certificates, so it reaches the feed everywhere.
- **Red means stuck again** (from 1.0.1). A session counts as stuck after ten minutes of silence, not three: Claude Code says nothing while a command runs, and it lets one run for ten minutes. A long build no longer turns the light red.
- **Clearer messages.** When the feed cannot be read, `blink update` and the service log now say why.

## Updating from 1.0.0 or 1.0.1 on a Mac

Those versions cannot fetch this one. Download the file for your Mac again and run it -- it installs over the old one and keeps your settings:

```bash
# macOS (Apple silicon)
curl -fsSL -o blink https://github.com/KfirLevy258/Blink/releases/latest/download/blink-macos-arm64
# macOS (Intel):  .../blink-macos-x86_64
chmod +x blink && ./blink
```

On Linux and Windows, the screen offers the update as usual; one tap installs it. From 1.0.2 on, every platform updates from the screen.

Something wrong? Email **support@blink-buddy.com** with the output of `~/.blink/bin/blink status`.
