**BLINK 1.0.4 finishes the Windows work.** One more thing the first Windows PC taught us, fixed.

## What changed

- **Usage arrives on a Windows PC whose language is not English.** BLINK read Claude Code's status line file in the machine's regional code page rather than as UTF-8. On a Hebrew Windows 10 the file -- which mentions the user's own folder -- could not be read at all, so the screen stayed on "connecting 2/2" although the figures were sitting right there. Every file BLINK reads or writes is now UTF-8 by name, on every platform.

Nothing changed on macOS or Linux beyond the version number.

## Updating

If you have 1.0.2 or newer, the screen offers the update; one tap installs it. On Windows with 1.0.3 or older, download `blink-windows-x86_64.exe` again and run it -- it installs over the old one. On a Mac with 1.0.0 or 1.0.1, download the file again too (see the [1.0.2 notes](https://github.com/KfirLevy258/Blink/releases/tag/v1.0.2)).

Something wrong? Email **support@blink-buddy.com** with the output of `blink status` and the last lines of `bridge.log`.
