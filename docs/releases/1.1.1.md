**BLINK 1.1.1 makes red mean one thing.** A small change to the activity light, made after two false alarms in a day.

## What changed

- **Red means a turn died on an error.** BLINK used to turn red when a session had announced work and then gone silent for a while -- ten minutes in 1.0.4. That guessed wrong twice in one day: once on a long-running command, once on a seventeen-minute think that was working the whole time. Claude Code's hooks cannot tell a long turn from a stuck one, so BLINK no longer guesses. The light stays green-pulsing for as long as a session is working, and turns red only when a turn actually fails -- a rate limit, an overloaded API, an authentication problem -- which Claude Code reports outright. Amber ("your turn") is unchanged. Same rule for Codex.

Nothing else changed.

## Updating

If you have 1.1.0, the screen offers this one; one tap installs it. On anything older, run the install line from the [1.1.0 notes](https://github.com/KfirLevy258/Blink/releases/tag/v1.1.0) once more.

Something wrong? Email **support@blink-buddy.com** with the output of `blink status` and the last lines of `bridge.log`.
