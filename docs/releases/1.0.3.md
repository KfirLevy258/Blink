**BLINK 1.0.3 is the Windows release.** The first install on a real Windows PC found three things; all three are fixed.

## What changed

- **It works when your Windows user name has non-English letters.** Claude Code on Windows could not run BLINK's hooks or status line when the path to them contained a character outside ASCII, so the screen stayed on "connecting 2/2" forever. The commands are now written in a form that works for every user name.
- **No window on the desktop.** The background service used to open a console window at every login. It now starts hidden, as a service should.
- **A log on Windows.** The service now writes `%USERPROFILE%\.blink\bridge.log`, the same file `blink status` and support point you at on macOS and Linux.

Nothing changed on macOS or Linux beyond the version number.

## Updating

If you have 1.0.2, the screen offers the update; one tap installs it. On a Mac with 1.0.0 or 1.0.1, download the file again and run it (see the [1.0.2 notes](https://github.com/KfirLevy258/Blink/releases/tag/v1.0.2)). On Windows, download `blink-windows-x86_64.exe` again and run it -- it installs over the old one.

Something wrong? Email **support@blink-buddy.com** with the output of `blink status` and the last lines of `bridge.log`.
