**BLINK 1.1.0 starts instantly.** The app used to take five to ten seconds to answer even `blink status`; it now answers at once. The download changed shape to make that happen, so please install this one by hand -- one command, below.

## What changed

- **The app starts in a fraction of a second.** It was shipped as one file that unpacked itself on every run -- 50 MB, every time, which macOS also scans every time. It is now a small folder that unpacks once, at install. Nothing else about it changed.
- **Updates keep working.** The screen still offers new versions and one tap still installs both halves; the app now swaps in a folder instead of a file, keeps the previous one until the new one has proven itself, and rolls back on its own if it does not.

## Installing 1.1.0

Every earlier version expects the old single-file download, so this one cannot arrive through the screen. Run the one line for your platform; it installs over what is there and keeps your settings.

```bash
# macOS (Apple silicon)
curl -fsSL https://github.com/KfirLevy258/Blink/releases/latest/download/blink-macos-arm64.tar.gz | tar xz && ./blink/blink
# macOS (Intel):  .../blink-macos-x86_64.tar.gz
# Linux:          .../blink-linux-x86_64.tar.gz
```

Windows (PowerShell or Command Prompt):

```
curl.exe -fsSL -o blink.zip https://github.com/KfirLevy258/Blink/releases/latest/download/blink-windows-x86_64.zip && tar -xf blink.zip && .\blink\blink.exe
```

You can delete the `blink` folder afterwards. From 1.1.0 on, updates come through the screen again.

Something wrong? Email **support@blink-buddy.com** with the output of `blink status` and the last lines of `bridge.log`.
