**BLINK 1.5.1 runs on Ubuntu 24.04 again.** The 1.5.0 download for Linux could not start on Ubuntu 24.04 and other systems of its age: the install finished, but the bridge never ran and the board was never found. This release fixes that. Nothing changes on macOS or Windows.

## What changed

- **The Linux download works on glibc 2.39 and newer** (Ubuntu 24.04, Debian 13, Fedora 40). The 1.5.0 one needed glibc 2.42, which only the newest distributions have. `blink status` showed `could not list serial ports` with `GLIBC_2.42 not found`, and the bridge kept restarting. Thanks to tomershay100, who reported it with the cause and a workaround.
- **An update that cannot start is no longer installed.** Before replacing itself, BLINK now checks that the new version can load everything the bridge needs, and keeps the version it has if not.

## If you are on Linux and 1.5.0 never started

The bridge is not running, so it cannot update itself. Install again with the one line from the README:

```bash
curl -fsSL https://github.com/KfirLevy258/Blink/releases/latest/download/blink-linux-x86_64.tar.gz | tar xz && ./blink/blink
```

## Updating

On macOS and Windows, and on Linux where 1.5.0 is running, **`blink update`** installs this version, then the screen offers the firmware and one tap installs it. The firmware is 1.5.0's with a new version number.

Something wrong? Email **support@blink-buddy.com** with the output of `blink status` and the last lines of `bridge.log`.
