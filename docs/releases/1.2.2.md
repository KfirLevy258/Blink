**BLINK 1.2.2 is a smaller download.** One trim, one fix.

## What changed

- **The app is a third smaller: about 12 MB to download instead of 18, and 25 MB on disk instead of 42.** Before writing firmware, the app checks that the chip is not one that needs encrypted images. The tool it used for that question dragged in a 12 MB cryptography library to answer one bit; the app now reads the bit itself. Nothing else about updates changed.
- **The app remembers the board it is talking to.** Its note of the board's id and firmware was only taken from the first message after a restart, which is never the one that carries them, so it stayed empty. Harmless (the board asks for updates itself), now correct.

The firmware is unchanged apart from its version number.

## Updating

The app updates itself; the screen then offers this firmware, and one tap installs it.

Something wrong? Email **support@blink-buddy.com** with the output of `blink status` and the last lines of `bridge.log`.
