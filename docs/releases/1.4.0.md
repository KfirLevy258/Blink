**BLINK 1.4.0 is about making the panel yours.** It brings twelve themes, light ones among them, and one you make yourself on your computer. Focus mode shows the window you watch as one big gauge, and each provider's page can now say when the service, not your machine, is having trouble.

## What changed

- **Twelve themes, and your own.** Dark (still the default, and exactly the look you had), Neon, Bold, Mono, Ocean, Synthwave, Forest, Retro LCD, Colour-blind, and three light themes for a bright room: Light, Light soft and Light ink. Pick one on the board in **Settings > Theme**, where each tile is drawn in its own colours.
- **Make a theme on your computer.** Run **`blink theme`**, or tap **Edit on computer** under Settings > Theme, and a theme builder opens in your browser. Every change shows on the board as you make it. Choose the colours, thin, normal or thick arcs, round or flat ends, and whether the dot shows. **Save** keeps it; **Cancel** or closing the tab puts back the theme you had. A custom theme has a share code starting `BT1.`, so you can send it to someone, and `blink theme reset` goes back to Dark.
- **The theme builder page has a new look**, with your board in the middle of it. Only the newest builder tab is live: an older one stops, says in the line at the top that the builder continued in a newer tab and, if it holds changes you had not saved, keeps its Copy share code button on. Nothing can be changed or saved until the builder has read the theme your board has now, so a slow start can never save over it.
- **Custom themes keep their small text readable.** The clock, the window names and other small labels are drawn in a softer shade of your text colour. On a low-contrast theme that shade got too faint to read, so it now moves toward the main text colour until it can be read.
- **Focus mode.** If you mostly watch one limit, **Settings > Focus** shows it as one big gauge: choose Session or Weekly. The other window stays on screen as a single dim line underneath.
- **Service status, per provider.** Turn it on with **`blink config status-page on`** and each provider's page says when that service has an incident, for example "Major outage" on the Claude page. A Codex outage shows on the Codex page, not over your Claude numbers. It clears by itself when the service recovers. It is off unless you turn it on, and while it is off BLINK makes no requests to the status pages at all.
- **A new Settings screen.** Four equal tiles, each with an icon: Brightness, Theme, Focus and Update.
- **Steadier numbers.** When Claude Code and Claude Desktop report the same window a fraction of a point apart, the dial no longer jumps back and forth between them. When a Codex limit resets while Codex is closed, the panel moves to the new window instead of holding the old figure until Codex is opened again.
- **The board restarts itself after a rare fault.** If it hits an internal fault while running, it restarts and picks up where it left off, where before the screen froze on its last reading. If faults keep repeating, it stops rather than restarting again and again.
- **An update installs the version it named.** If a newer version arrives while the update offer is on the screen, the offer changes to name it, and **Update now** no longer installs a version other than the one shown.
- **Claude Desktop from the Microsoft Store.** A recent Store build of Claude Desktop on Windows moved its data to a new folder, and BLINK lost sight of it: no Desktop figures, and `blink status` saying Desktop was not installed. BLINK now follows the app to the folder it uses, and `blink status` names it.
- **Clearer status messages.** `blink status` says when Claude Desktop simply has not recorded any usage yet, which is normal right after signing in, instead of saying its file failed to read. Running BLINK from a downloaded copy of the source now names a command that exists, and asks you to keep that folder.

## Updating

Run **`blink update`** to install this version, then the screen offers the firmware and one tap installs it.

Your edition, logo, brightness and every other setting are kept. Themes and Focus start at Dark and off, so the panel looks exactly as before until you pick something new. If you ever go back to 1.3.4, the board still starts with your settings.

Automatic app updates are off for this release, so nothing installs on its own.

Something wrong? Email **support@blink-buddy.com** with the output of `blink status` and the last lines of `bridge.log`.
