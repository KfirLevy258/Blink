**BLINK 1.0.0 is the first release built for the device you can buy.** Everything before it was for the people building BLINK; this one is for the people using it.

## What BLINK does

BLINK is a small screen that sits on your desk and shows how much of your Claude Code and Codex usage you have spent: the **5-hour session** and the **7-day week**, each as a dial with a countdown to its reset. It plugs into your computer over USB, sets itself up with one command, and updates itself.

It reads only figures that Claude Code, Claude Desktop and Codex have already written to your own disk. It never sees a credential, never signs in to anything, and never sends anything anywhere. There is no account, no cloud and no telemetry.

## What is in 1.0.0

- **Two dials, two countdowns** for Claude Code, and a second page for Codex: tap the name or swipe to switch.
- **The light tells you when it is your turn.** It goes amber the moment any session -- Claude or Codex -- has finished an answer or is asking permission, even while others are still working; pulses green while everything is busy; turns red if a session is stuck or you have hit a rate limit.
- **Claude Desktop alone works too**, showing both percentages and how fast the window is filling.
- **Updates over the cable.** When a new version exists the screen asks; one tap updates the device and the app together. Both halves are signed, and a failed update rolls back on its own.
- **Company editions.** A device built for a company shows the company's logo after the boot animation.

## Setting up

One file. Download it for your platform, run it, delete it. It installs itself under `~/.blink`, starts at every login, and finds the board on its own.

```bash
# macOS (Apple silicon)
curl -fsSL -o blink https://github.com/KfirLevy258/Blink/releases/latest/download/blink-macos-arm64
# macOS (Intel):  .../blink-macos-x86_64
# Linux:          .../blink-linux-x86_64
chmod +x blink && ./blink
```

On Windows, download `blink-windows-x86_64.exe` and run it.

Needs Claude Code 2.1.100 or newer. The installer changes one file, `~/.claude/settings.json`, says exactly what it changes before it does, keeps any status line you already had, and undoes all of it with `~/.blink/bin/blink uninstall`.

## If something is wrong

`~/.blink/bin/blink status` says whether the service is running and what it is reading. Unplug the board and plug it back in. If that does not fix it, email **support@blink-buddy.com** with the output of `blink status` and the last lines of `~/.blink/bridge.log` -- neither contains anything private.

## The fine print

The software is open source under the MIT license. The BLINK name and logo are not part of that license. The board is an ESP32-2432S028; the firmware is Zephyr; the app is one Python binary.
