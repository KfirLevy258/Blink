**BLINK 1.0.1 stops the light crying wolf.** The one change is to when the dot turns red for a stuck session.

## What changed

- **Red means stuck again.** 1.0.0 called a session stuck after three minutes of silence. Claude Code says nothing while a command is running, and it lets a single command run for ten minutes -- so a long build or test turned the light red while everything was fine. The line is now ten minutes, longer than any one command is allowed, for Claude Code and Codex alike. Red once more means something needs you.

Nothing else moved. The firmware is rebuilt so the two halves carry the same number; the screen looks and behaves exactly as before.

## Updating

If you already have BLINK, the screen will offer the update; one tap installs it. Setting up for the first time is the same as [1.0.0](https://github.com/KfirLevy258/Blink/releases/tag/v1.0.0): download the file for your platform, run it, delete it.

Something wrong? Email **support@blink-buddy.com** with the output of `~/.blink/bin/blink status`.
